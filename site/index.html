I — The Problem

EVERY AGENT IS A TRICKSTER

Agents write fast, reason fluently, and talk their way out of review. Left alone they rewrite the rules they were given, touch the files that judge them, and leave a chat transcript as the only record — a transcript that evaporates.

Loki puts deterministic checks around them. It blocks edits to its own policy files before they happen, checks source files after each write, and runs repository-wide checks in CI.

Schema-valid ≠ correct.

II — What runs on every write

THE BINDING

Two gates on every change: one before the write lands, one after.

BEFORE THE WRITE

  • Writes to .loki/** are rejected outright.
  • Agent hook files are rejected.
  • CI policy files are rejected.
  • Configured quality files are rejected.

LOKI_ALLOW_PROTECTED=1 is the only bypass — reserved for an intentional policy change that will receive separate review.

AFTER THE WRITE

  • Python — Ruff plus import and AST checks
  • JavaScript / TypeScript — Oxlint
  • Go — golangci-lint and go test
  • Rust — Clippy
  • Elixir — Credo and compilation with warnings as errors

Repository scans also detect removed tests, deleted assertions, new skips, dependency manifest drift, undeclared Python imports, suspicious package names, and configured contract, property, differential, or mutation commands.

V — Install & daily use

THE INCANTATION

Run the installer from a Loki checkout and point it at a Git repository. It copies Loki into .loki/, adds the agent adapters, and installs starter configuration for Ruff, Oxlint, golangci-lint, and GitHub Actions.

the binding, spoken aloud
# bind a repository
$ python3 /path/to/loki/loki.py init --dir /path/to/repository
loki copied to .loki/ — agent adapters and starter configuration installed
# check the installation
$ python3 .loki/loki.py scan
repository scan complete
# in CI, a missing compiler or linter fails the job
$ python3 .loki/loki.py scan --strict --base origin/main

After installation: Codex — run /hooks and approve the project hooks. Pi — accept the project trust prompt. Factory Droid loads .factory/hooks.json; Claude Code and OMP need no extra Loki approval. Add --online to check package names against their public registries.

VI — Project policy

THE POLICY

Policy lives in .loki/loki.json. The installer starts with:

{
  "approved_dependencies": [],
  "commands": {
    "contract": [],
    "property": [],
    "differential": [],
    "mutation": []
  }
}

Add repository-owned commands as arrays of arguments. Loki runs them during a repository scan and reports their output under the command group.
